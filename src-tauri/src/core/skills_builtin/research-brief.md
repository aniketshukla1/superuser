Produce `research-brief.md`:

# <Topic>
**Answer in one paragraph** — the conclusion first, for someone who reads no further.

## What the sources say
Three to six findings. Each one ends with a link to the primary source you actually
opened. Prefer primary sources (filings, docs, papers, official pages) over summaries.

## Disagreements and gaps
Where sources conflict, and what nobody answered.

## Sources
A numbered list of every URL you used, with one line on what each contributed.

Rules: never cite a page you did not read; if a claim rests on a single source, say
so. If the web is unavailable, stop and tell the user rather than answering from
memory and presenting it as researched.
